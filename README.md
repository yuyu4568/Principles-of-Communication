## 📚 笔记内容

### 第一章 绪论（上两节课）

1. 消息 / 信息 / 信号 三大基本概念及关系
2. 通信与通信系统的定义、一般模型框图（含 AWGN 噪声源）
3. 模拟 / 数字通信系统组成与框图差异
4. 通信方式分类（单工、半双工、全双工，并行/串行、同步/异步）
5. **信息及其度量（重点）**：自信息量公式、三种单位（bit/nat/Hartley）、信源熵、例题 1-1 / 1-4 详解（两种计算方法对比）
6. **通信系统主要性能指标（重点）**：码元速率 R_B 与信息速率 R_b、频带利用率 η、误码率与误信率
7. 课堂练习 3 题全解 + 易错点与考试提示 + 第一章思维导图
8. **扩充内容**：信息量的可加性、波特率/比特率在串口场景的区分、奈奎斯特准则与香农公式给出的频带利用率理论上限

### 第二章 确知信号（本节课）

1. 本章定位：确知信号 / 随机过程不作为课程重点，但为后续章节打基础
2. 信号的表示：定义、数学表示 s(t)、时域 / 频域两个物理视角
3. 确知信号 与 随机信号（噪声 n(t)）的定义与分类架构
4. **分类一：周期信号与非周期信号**——基波 T₀ / 基频 f₀、正弦波与方波及谐波叠加；δ(t)、u(t)、指数衰减、高斯脉冲、心电图
5. **分类二：能量信号与功率信号**——归一化功率、能量 E=∫s²dt、平均功率截短定义、总结表；周期信号平均功率 = 单周期平均功率
6. **例题精讲**：e^(−at)·u(t) 为能量信号（E = 1/2a）；斜坡 t·u(t) 既不是能量信号也不是功率信号
7. **周期信号频谱（傅里叶级数）**：C_n 离散谱、直流分量 C_0、共轭对称 → 幅度谱偶对称 / 相位谱奇对称、实偶信号 C_n 为实函数
8. **非周期信号频谱密度（傅里叶变换）**：S(f) 连续谱（V/Hz）、C_n 与 S(f) 区别、门函数 τ·Sa(πfτ) 与带宽 1/τ、δ(t) 三性质、余弦波频谱、常用傅里叶变换对
9. **能量谱密度 G(f)=|S(f)|²** 与**帕塞瓦尔定理**（时域 ↔ 频域能量守恒）
10. **功率谱密度 P(f)**（截短法）与**周期信号功率谱 P(f)=Σ|C_n|²δ(f−nf₀)**（教材公式 2.2-36、例 2-7）
11. **相关函数入门**：自相关 / 互相关，维纳-辛钦定理（衔接第三章随机过程）
12. 易错点清单、考试提示、第二章思维导图（含 9·18 防空警报 = OOK 通断键控小知识）
