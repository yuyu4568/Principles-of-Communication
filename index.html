1课堂回顾：消息·信息·信号 与 通信系统模型

1.1 三个基本概念（老师说“必记”）

  • 消息 (Message)：通信中要传递的原始对象，可以是文字、语音、图像、数据等；分为连续消息（取值连续，如语音）和离散消息（取值有限/可数，如电报符号、数字）。
  • 信息 (Information)：消息的内涵——对接收者而言不确定性的消除。同一句话对不同人“信息量”可能不同，这正是 1.4 节要解决的问题。
  • 信号 (Signal)：消息的载体，是消息的物理表现形式，可以是电信号、光信号等。
🔑 三者关系（考试高频填空/简答） 信息的表现形式是消息；消息的内涵是信息；信号是消息的载体。

通信：利用电信号（或光信号）等载体，把消息中的有效内容（即信息）从发送端安全、有效地传送到接收端的过程。

通信系统：完成通信过程所需的全部电子设备 + 信道的总和（发送端设备 + 接收端设备 + 中间传输介质）。

1.2 通信系统的组成（老师说“期末常考画图题和简答题”）

信源→ 发送设备→ 信道→ 接收设备→ 信宿
噪声源（加性噪声，通常为高斯白噪声 AWGN）叠加在信道上
  • 信源：产生消息及其原始电信号；信宿：接收并还原消息；
  • 发送设备：把原始信号变换成适合在信道中传输的形式（编码、调制、放大等）；
  • 信道：传输信号的物理媒介，分有线信道（同轴电缆、光纤等）和无线信道（自由空间）；
  • 接收设备：发送设备的逆变换（放大、解调、译码等）；
  • 噪声源：信道中必然存在，建模为加性噪声，通信原理中通常假设为高斯白噪声（AWGN）。

1.3 模拟系统与数字系统的框图差异

系统类型发送设备主要环节接收设备主要环节
模拟通信系统

💡 扩充：各环节在干什么？ 信源编码：去除冗余（压缩），把模拟/信源符号变成二进制数字流；加密：保证信息安全；信道编码：加入可控冗余（纠错码，如汉明码、RS 码），提高抗干扰能力；调制：把数字比特流搬移到适合信道的频段（如 PSK/QAM）。接收端各环节为对应逆过程。

1.4 课堂引言与通信方式分类

21.4 信息及其度量（本课重点）

2.1 为什么要度量信息？

通信系统传输的对象是“消息”，而真正有价值的是消息中包含的“信息”。度量信息的目的：定量衡量消息中携带信息的大小，从而衡量通信系统的传输能力。

2.2 课堂直观例子：信息量 = 概率的函数

  • 停课调查：老师问卷“明天太阳照常升起”vs“明天停课一天”，绝大多数同学觉得“停课”信息量大——因为 事件发生概率越小，不确定性越大，信息量越大；“太阳从东方升起”概率≈1，几乎不含新信息（信息量≈0）。
  • 文本压缩（zip）：内容全是重复字符的文本，压缩后体积大幅缩小；随机性大（每个字符都“意外”）的文本几乎压不动。因为压缩算法（类霍夫曼编码）给高概率（信息量小）的符号分配短码，给低概率（信息量大）的符号分配长码。
  • 摩斯电码：字母 E 只用一个点“·”（最短码），因为它在英文中出现概率最高、信息量最小；Q、Z 等罕见字母的码更长。这正是“概率大→信息量小→码长短”的直观体现。

2.3 信息度量的两个原则（书上要点）

  1. 度量方法与消息的种类无关（文字、语音、图像都可用同一套数学方法度量）；
  2. 度量方法与消息的重要程度无关。

信息量只与事件发生的概率（不确定性）一一对应：概率 → 0 时信息量 → ∞；概率 → 1 时信息量 → 0。

2.4 自信息量（单符号信息量）公式【必记公式 ①】

I(x) = loga [1 / P(x)] = − loga P(x)
  • P(x) 为符号 x 出现的概率；
  • 对数底 a 决定单位：
底数 a单位说明
a = 2比特（bit）最常用；对应二进制 0/1 的一次等概率选择
a = e奈特（nat）1 nat ≈ 1.44 bit
a = 10哈特（Hartley）1 Hartley ≈ 3.32 bit
💡 扩充：信息量的可加性 对两个相互独立的事件 x、y，其联合事件所含的信息量等于各自信息量之和：I(xy) = I(x) + I(y)。这正是定义取对数形式的原因——它把“概率相乘”转化为“信息量相加”，使度量更方便。对熵同样成立（独立信源的联合熵 = 各熵之和）。
❗ 老师特别强调 做填空题/计算题时，算完信息量必须写单位“比特(bit)”，漏写单位要扣分！工程表述要严谨。

2.5 例题 1-1：二进制离散信源（书上例 1-1）

✏️ 题目 设一二进制离散信源，以相等的概率发送数字 0 或 1（即 P(0)=P(1)=1/2）。求信源每个符号输出的信息量。

解：I(0) = I(1) = −log2(1/2) = log2 2 = 1 bit。

含义：等概率发送 0/1 时，每个二进制码元恰含 1 比特信息，所以习惯上把一个二进制码元称为“1 比特”。

2.6 推广：M 进制等概率信源

若 M 进制信源各符号等概率（P = 1/M），则每个符号的信息量为：

I = log2 M  （bit/符号）
进制 M概率信息量二进制位数 K
二进制 (M=2)1/2log22 = 1 bit1 位（0、1）
四进制 (M=4)1/4log24 = 2 bit2 位（00、01、10、11）
八进制 (M=8)1/8log28 = 3 bit3 位
M 进制 (M=2K)1/Mlog2 M = K bitK 位

本质：1 个 M 进制符号可以用 K 位二进制表示，故携带 K 比特信息——这也是计算机内部一切信息都用比特表示的原因。

2.7 平均信息量（信源熵）H(X)【必记公式 ②——本课最重要公式】

实际信源各符号往往非等概率。对长度为 N 的符号序列，每个符号的“平均”信息量要用统计平均（数学期望）：

H(X) = − ∑i=1M P(xi) · log2 P(xi)   (bit/符号)
  • H(X) 称为信源熵（Entropy，香农 1948 年提出），是信源每个符号携带的平均信息量；
  • 要求：P(xi) ≥ 0 且 ∑ P(xi) = 1；各符号相互独立；
  • 等概率时 H(X) = log2 M，达到最大值（最大熵原理）；
  • 公式也写作 H(X) = ∑ P(xi) · I(xi)，即“概率 × 自信息量”的加权和。

2.8 例题 1-4：非等概率信源与一段消息的信息量（课上完整求解）

✏️ 题目（教材例 1-4） 离散信源由 0、1、2、3 四个符号组成，出现概率分别为 P(0)=3/8、P(1)=1/4、P(2)=1/4、P(3)=1/8（总和=1，各符号独立）。一段消息为
201020130213001203210100321010023102002010312032100120210
求该消息的总信息量（两种方法）。

第一步：求每个符号的自信息量

I(0) = −log2(3/8) = log2(8/3) ≈ 1.415 bit
I(1) = −log2(1/4) = 2 bit
I(2) = −log2(1/4) = 2 bit
I(3) = −log2(1/8) = 3 bit

第二步：数消息中每个符号的个数（共 57 个符号：0 出现 23 次、1 出现 14 次、2 出现 13 次、3 出现 7 次）

方法一：算术统计法（逐个符号统计加总）

I总 = 23×1.415 + 14×2 + 13×2 + 7×3 = 107.55 ≈ 108 bit

方法二：熵法（先求平均信息量，再乘以符号总数）

H = −[ (3/8)log2(3/8) + (1/4)log2(1/4) + (1/4)log2(1/4) + (1/8)log2(1/8) ] ≈ 1.906 bit/符号
I总 = N × H = 57 × 1.906 ≈ 108.64 bit
🔑 两种方法为什么结果略有差别？ 方法一是“实际发生的信息量”（按消息中真实计数统计）；方法二是“统计平均意义下的信息量”（按概率期望 × 长度）。消息越长，两种结果越接近（大数定律）。短消息适合用方法一，长消息用方法二更简便。考试两种方法都要会。

2.9 连续消息的信息量（了解即可）

对取值范围连续的连续信源，概率用概率密度函数 f(x) 描述（f(x)·dx 是落在小区间内的概率），其平均信息量（称为连续信源熵/微分熵，也叫相对熵）为：

h(X) = − ∫−∞+∞ f(x) · log2 f(x) dx
💡 扩充 课堂老师说“连续消息不作为考试重点，但要会算”。这里只要求：知道连续信源用概率密度函数、用积分代替求和即可。典型结论：高斯分布（方差 σ²）的连续熵为 (1/2)log2(2πeσ²)，在给定方差下高斯分布熵最大。

2.10 知识扩充：熵的性质与压缩的关系

  • 非负性：H(X) ≥ 0，等号仅在某个符号概率为 1（其余为 0）时成立——此时信源完全确定，不含信息；
  • 最大熵：等概率时熵最大，H_max = log2 M；越“平均”的信源，平均信息量越大；
  • 二进制熵函数：只有 0/1 两符号（概率 p 与 1−p）时，H = −p·log2p − (1−p)·log2(1−p)，在 p=0.5 时取最大值 1 bit；p=0 或 1 时 H=0；
  • 与压缩编码的联系（老师用 zip 举例的深意）：香农第一定理（无失真信源编码定理）指出——无损压缩的极限就是信源熵；霍夫曼（Huffman）编码按“概率大→码长短”构造，平均码长 ≥ 熵，且可任意逼近。

31.5 通信系统主要性能指标（本课重点）

3.1 两大指标总览：有效性 与 可靠性

  • 有效性（Effectiveness）：在给定信道条件下，系统传输信息的速度/效率——“传得快、省频带”；
  • 可靠性（Reliability）：系统正确传输信息的能力——抗噪声、抗干扰，“传得准”；
🔑 有效性与可靠性是一对矛盾（老师说“可互换”） 提高有效性往往降低可靠性，反之亦然。例如加密/纠错编码会牺牲一部分有效性（多传冗余比特）来换取可靠性；工程上需要在两者之间折中平衡。
系统类型有效性指标可靠性指标
模拟通信系统传输带宽 B（Hz）——带宽越窄越有效输出信噪比 SNR = S/N（信号功率/噪声功率）——越大越可靠
数字通信系统频带利用率 η（Baud/Hz 或 bit/s/Hz）差错概率 Pe（误码率），还有误信率 Pb
💡 扩充：模拟系统“带宽换信噪比” 调频（FM）广播比调幅（AM）广播占用更宽频带，但抗干扰能力（输出信噪比）显著更好——这就是典型的“用有效性换可靠性”。

3.2 码元传输速率 RB（传码率 / 波特率）

  • 定义：每秒传输的码元（符号）个数；
  • 单位：波特（Baud）；
  • 公式（Ts 为一个码元持续时间）：
RB = 1 / Ts   (Baud)
  • 例：1 秒内传 1000 个码元 → RB = 1000 波特；硬件串口常见的 9600、115200 这类“波特率”设置，在二进制电平信号下数值上正好等于 bit/s（见 3.3），所以工程上常把二者混称；
  • RB 与进制数（M）无关、与信源统计特性无关——它只管“每秒甩出多少个码元”。

3.3 信息传输速率 Rb（传信率 / 比特率）

  • 定义：每秒传输的信息量；
  • 单位：比特/秒（bit/s，简写 b/s 或 bps）；
  • 与 RB 的关系——通过信源熵 H 联系起来：
Rb = RB · H(X)
  • 等概率时（H = log2 M，M=2K）：
Rb = RB · log2 M
  • 特别地，二进制（M=2）等概率时，Rb 与 RB 数值相等，但单位不同（bit/s vs Baud），做题必须区分：大 B = 波特率，小 b = 比特率。
码元传输速率 RB信息传输速率 Rb
别名传码率 / 波特率传信率 / 比特率
定义每秒传输的码元个数每秒传输的信息量
单位波特（Baud）比特/秒（bit/s、bps）
决定因素只与码元宽度 Ts 有关与 RB 和每符号平均信息量 H 有关
关系Rb = RB·H；等概率时 Rb = RB·log2M

3.4 频带利用率 η（数字系统有效性指标）

单位频带（1 Hz）内能传输的速率，有两种写法：

η = RB / B   (Baud/Hz)   或    ηb = Rb / B   (bit/s/Hz)
  • B 为系统传输带宽（Hz）；
  • 两种写法单位不同；二进制等概率时两者数值相同；
  • η 越大，说明用同样带宽能传更多信息，系统越“有效”。
💡 扩充：频带利用率的理论上限（提前了解，与后续章节衔接） 奈奎斯特准则：理想无噪声低通信道下，码元速率上限为 RB(max) = 2B（B 为带宽），所以二进制时频带利用率上限为 2 bit/(s·Hz)；香农公式 C = B·log2(1 + S/N) 则给出了有噪信道下信息速率（比特率）的绝对上限——频带利用率不可能无限提高，这正是“有效性与可靠性相互制约”的深层原因。实际系统的 η 都在这些理论上限之下。

3.5 可靠性指标：误码率 Pe 与误信率 Pb

Pe（误码率）= 错误接收的码元数 / 传输的总码元数   （无单位）
Pb（误信率）= 错误接收的信息量（比特数）/ 传输的总信息量（比特数）
  • 二者都没有单位（比值）；
  • 若每个错误码元中只错 1 个比特，四进制（每码元 2 bit）时：Pb = Pe / log2 M，即 Pb = Pe / 2；
  • 课堂标准：正常通信要求误码率 Pe < 10−4；
💡 扩充：不同业务的误码率要求 语音 10−3～10−6（人耳可容忍少量差错），数据/计算机通信一般要求 10−6 以下，重要数据可要求 10−9～10−12。误码率由信道质量、调制/编码方式、信噪比共同决定。

4课堂练习精讲（3 题全解，含完整步骤）

练习 1：比较两个数字系统的有效性

✏️ 题目 系统 A 用 2PSK 调制，信息传输速率 Rb = 2400 bit/s，所需带宽 B = 2400 Hz；系统 B 用 4PSK 调制，Rb = 2400 bit/s，所需带宽 B = 1200 Hz。问哪个系统更有效？（PSK：相移键控，属数字调制，第 7 章讲授）

解：比较数字系统有效性，看频带利用率 ηb = Rb/B：

ηA = 2400 / 2400 = 1 bit/s/Hz  ；  ηB = 2400 / 1200 = 2 bit/s/Hz

结论：系统 B 更有效——它用一半的带宽传同样多的信息。老师在课上指出：比较结果与“几进制调制”本身没有直接关系，关键看 Rb 与带宽 B 的比值（就本题条件而言，4PSK 因谱效率高而胜出）。这类题常以填空题出现。

练习 2：波特率 → 比特率 换算

✏️ 题目 某数字传输系统以 1200 波特（Baud）的速率传送二进制码元（等概率）。① 求信息速率 Rb；② 若改为八进制、速率不变，求 Rb。

解（等概率，Rb = RB·log2M）：

① 二进制：Rb = 1200 × log22 = 1200 bit/s
② 八进制：Rb = 1200 × log28 = 1200 × 3 = 3600 bit/s

注意：同样 1200 波特，八进制每个码元携带 3 比特，所以比特率是二进制的 3 倍。

练习 3：由码元持续时间求速率 + 误码率与误信率

✏️ 题目 某四进制数字传输系统，已知码元持续时间（宽度）为 Ts，则码元速率为 RB = 1/Ts = 1200 波特（课堂条件）。该系统连续工作 1 小时，接收端共收到 6 个错码，且每个错码中仅发生 1 个比特错误。求系统的误码率 Pe 与误信率 Pb。

解：

  • 1 小时内的总码元数：N = RB × t = 1200 × 3600 = 4.32×106 个码元；
  • 总比特数：N × log24 = 4.32×106 × 2 = 8.64×106 bit；
Pe = 6 / (4.32×106) ≈ 1.39×10−6（误码率）
Pb = 6 / (8.64×106) ≈ 6.94×10−7（误信率）

关联验证：每个错码只错 1 bit，四进制每码元 2 bit，故 Pb = Pe / log24 = 1.39×10−6/2 = 6.94×10−7 ✔

✅ 解题套路小结（老师提示） ① 给出 Ts → 先求 RB = 1/Ts；② 用 Rb = RB·log2M 求比特率；③ 误码率/误信率 = 错的数量 ÷ 总的数量（注意码元与比特要分别计数）；④ 写结果保留有效数字并注明是什么率。

5易错点与考试提示（老师原话提炼）

🚨 高频失分点 ① 漏写单位：信息量必须写“bit”，波特率写“Baud”，比特率写“bit/s”，否则扣分；
② 混淆 RB 与 Rb：大 B 是波特率（码元/秒），小 b 是比特率（bit/s），二进制等概率时数值相等但单位不同；
③ 混淆进制与每符号比特数：四进制每符号 2 bit、八进制 3 bit，换算用 log2M；
④ 误码率忘记“无单位”：Pe、Pb 都是比值，没有单位；
⑤ 画图题丢环节：数字通信系统模型必画全“信源→信源编码→加密→信道编码→调制→信道→解调→信道译码→解密→信源译码→信宿”，且噪声源叠加在信道。
  • 画图题/简答题：通信系统一般模型、数字通信系统模型是期末高频题，每个环节的作用要会描述；
  • 信息量计算三步走：写概率 → 代入公式 I = −log2P → 加单位“bit”；
  • 熵公式必须能默写：H(X) = −∑ P(xi)log2P(xi)，两个必记公式（自信息量 + 熵）老师课上反复强调；
  • 有效性比较题：看到“哪个系统更有效”立即想 η = Rb/B 或 RB/B；
  • 学习态度提醒（老师原话）：测试题要自己动脑做，不要直接丢给 AI 工具生成答案，否则失去总结课堂内容的作用。

2.1导入：信号是什么？怎么表示？

2.1.1 信号的定义

信号 (Signal)：表示消息的某种电的（或其他）物理量，是消息传输的载体；通信就是以信号的形式传输消息中的有效内容（信息）。

最常见的物理形式：电流、电压、电磁场 / 电磁波。

2.1.2 数学上的表示：信号是自变量的函数

  • 信号可表示为一个或多个自变量的函数，例如 s(t)、f(x)、g(x, y) 等；通信中最常见的是以时间 t 为自变量的 s(t)。
  • 最简单的语音信号例子：
s(t) = A·cos(ωc·t + φ)

2.1.3 物理形态上的表示：时域波形 / 频域频谱

  • 时域：横轴为时间 t、纵轴为 s(t) 的波形图；
  • 频域：横轴为频率 f、纵轴为 S(f) 的频谱图。例如正弦波时域是等幅振荡波形，频域是在 ±f0 处的谱线（δ 函数）；
  • 结论：可以根据信号的不同特征对信号分类（是否周期、能量是否有限、取值是否确定……）。

2.2确知信号 vs 随机信号

  • 确知信号（确定信号）：在任意一个时刻取值都是已知的，可以用一个已知、明确的数学关系（表达式）描述的信号。不同教材译名略有差异（确知 / 确定），指同一概念。
  • 随机信号（非确知信号）：不能用明确的数学关系描述，下一时刻取值不确定；最典型的代表是噪声 n(t)。
  • 随机过程（第三章内容）分为平稳随机过程与非平稳随机过程，随机信号是随机过程的一个现实（样本函数）。
信号→ 确知信号（可明确数学描述） / 随机信号 = 非确知信号（如噪声 n(t)）→ 随机过程：平稳 / 非平稳

2.3分类一：周期信号 与 非周期信号

2.3.1 周期信号

满足无始无终、按相同规律重复的特征：

s(t) = s(t + T0)
  • T0：满足上述重复规律的最小正间隔，称为基波（基本周期）；
  • f0 = 1 / T0：称为基频；
  • 典型例子：单频正弦波 s(t) = A·cos(2πf0t)，方波，以及若干频率为基频整数倍的正弦波叠加（如 sin2πf·t + sin2π(3f)·t，频率存在公倍数）。

2.3.2 非周期信号

不满足上述重复特征（不存在最小正周期）的确知信号：

  • 典型例子：单位冲激函数 δ(t)、单位阶跃函数 u(t)、指数衰减（瞬态）信号、高斯脉冲、心电图信号；
  • 注意特例：两个不同频率的正弦波叠加，若频率不成整数倍（没有公倍数），叠加结果仍为非周期信号；
  • 观察方式：左边看时域波形、右边看对应频谱，可以帮助直观判断。

2.4分类二：能量信号 与 功率信号

2.4.1 预备：归一化功率与信号能量

  • 归一化功率：实际功率 P = V² / R = I²·R，令 R = 1Ω（单位电阻）后，P 只由电压 / 电流决定：
P归一化 = v²(t) = i²(t)   （单位：W 瓦特）  |   能量单位：J（焦耳）
  • 功率与能量的关系：功率 = 能量 ÷ 时间；
  • 瞬时（归一化）功率：p(t) = s²(t)（在单位电阻上，电压平方即瞬时功率）；
  • 信号能量：瞬时功率对全部时间积分（推导：先取瞬时功率 s²(t)，再对整个时间轴积分）：
E = ∫−∞+∞ s²(t) dt   （单位：J）

2.4.2 能量信号

若能量 E 是大于 0、小于正无穷的有限定值，则该信号是能量信号；此时其平均功率趋于 0。

🔑 能量信号：0 < E < ∞（有限）→ 平均功率 P → 0 典型例子：单个矩形脉冲、指数衰减 / 瞬态信号、高斯脉冲等典型的非周期信号。

2.4.3 功率信号

若能量无限，则改用平均功率（截短法）判断：在 [−T/2, T/2] 内先算平均功率，再让 T → ∞ 取极限：

P = limT→∞ (1/T) · ∫−T/2T/2 s²(t) dt

若平均功率 P 是正的有限值，则该信号是功率信号；此时其总能量趋于无穷。

🔑 功率信号：0 < P < ∞（有限）→ 能量 E → ∞ 典型例子：周期信号、直流信号、随机信号——即“一般持续时间无限的信号”。注意老师强调是“一般”，并非所有持续时间无限的信号都是功率信号（个别特殊信号例外）。

2.4.4 结论总结（教材 p.17-18）

类型能量 E平均功率 P典型例子
能量信号 有限定值（0 < E < ∞） 趋于 0 单个矩形脉冲、指数衰减信号、高斯脉冲、一般非周期信号
功率信号 趋于 ∞ 有限正值 周期信号、直流、随机信号（一般持续时间无限的信号）
⚠️ 易错 不是能量信号，不一定就是功率信号——信号可能既不是能量信号也不是功率信号（见 2.5 例题）。判断顺序：先算能量 → 有限则能量信号；否则算平均功率 → 有限则功率信号；两者都无限则都不是。

2.4.5 周期信号的平均功率 = 一个周期内的平均功率

把 T 写成 N 个周期 T0 的叠加（T = N·T0，N → ∞）：

P = limT→∞ (1/T)∫−T/2T/2 s²(t)dt = (1/T0) · ∫T₀ s²(t) dt = 一个周期内的平均功率

其总能量 E = limN→∞ N·(单周期能量) = ∞，因此周期信号属于功率信号。

💡 课堂 MATLAB 演示（矩形脉冲 == 能量信号） 老师用 MATLAB 演示了判断流程：时间轴 t 从 −2s 到 2s（采样间隔很密），取宽度 τ = 0.5s（−0.25 ~ +0.25）、幅度为 1 的单个矩形脉冲； 用数值积分 E = trapz(t, x_rect.^2) 求得能量 E = 0.5 J（有限） → 能量信号； 再用 fft 快速傅里叶变换画频域图（subplot 分上下两个图、xlim 限制横轴范围）。指数衰减信号、高斯脉冲同理，能量均有限，都是能量信号。

2.5例题精讲：判断能量 / 功率信号

例 1（教材例 2-1 同类）：x(t) = e−at·u(t)，a > 0 t ≥ 0 时指数衰减，t < 0 时为 0，所以积分限只需从 0 到 +∞：
E = ∫0∞ (e−at)² dt = ∫0∞ e−2at dt = 1 / (2a)
（复合函数积分：把 e−2at 看成 eu、u = −2at 再积分）因为 a > 0 已知，所以 1/(2a) 是有限值 → 能量信号。
例 2：x(t) = t·u(t)（斜坡信号，t > 0 时值无限增大） 先看能量：E = ∫0∞ t² dt = ∞，不是能量信号； 再看平均功率：P = limT→∞ (1/T)·∫0T/2 t² dt = ∞，也不是功率信号。
结论 x(t) = t·u(t) 既不是能量信号，也不是功率信号。一看到“随时间无限增大的一次函数”，就知道能量必为无穷。
🔑 判断三步走（考试套路） ① 求能量 E = ∫s²(t)dt：有限 → 能量信号；② E 无限则求平均功率 P（截短 + 极限）：有限 → 功率信号；③ 两者都无限 → 两者都不是。

2.6频率性质（一）：周期信号的频谱 —— 傅里叶级数

分析信号频率性质用“三大域”：时域、幅频（幅度谱）、相频（相位谱）；幅频与相频统称频域。周期信号用傅里叶级数展开：

指数形式：s(t) = Σn=−∞+∞ Cn·ej2πnf0t，  ω0 = 2πf0 = 2π/T0
系数（即频谱）：Cn = (1/T0) · ∫T₀ s(t)·e−j2πnf0t dt
  • Cn 是离散谱（线谱）：只在频率 f = nf0 处有值，0、±f0、±2f0……表示各次谐波的幅度与相位（老师用视频演示了“谐波逐个叠加 / 拆分”的过程）；
  • n = 0 → C0 为直流分量：等于信号的时间平均值（一个周期内的平均）；
  • f0 为基频，n·f0 为第 n 次谐波频率。

频谱的重要性质（针对实信号）

C−n = Cn*（共轭对称）
  • 正频率部分与负频率部分是复数共轭关系；
  • ⇒ 幅度谱偶对称（|C−n| = |Cn|，模偶对称）；相位谱奇对称（关于原点对称）。

实偶 / 非偶信号的频谱

  • s(t) 为实偶信号（如对称矩形脉冲）→ Cn 是实函数，可写成抽样函数 Sa 形式的离散谱（例题验证）；
  • s(t) 为非偶信号 → Cn 是复函数（例题中出现虚部）；
  • 三角形式傅里叶级数本质相同：直流分量 C0 ＋ 各次谐波的线性叠加（各谐波振幅与相位可由 Cn 导出，之前课程已学过，只需记住结论）。

2.7频率性质（二）：非周期信号的频谱密度 —— 傅里叶变换

非周期（能量）信号用傅里叶变换得到频谱密度：

正变换：S(f) = ∫−∞+∞ s(t)·e−j2πft dt  （对 t 积分后只含频率 f → 频谱密度）
逆变换：s(t) = ∫−∞+∞ S(f)·ej2πft df  （用 ω 表示时为 (1/2π)∫F(ω)ejωtdω）
  • |S(f)| 为幅频特性，φ(f) = arg[S(f)] 为相频特性；
  • “对谁积分，谁就被消掉”——正变换消去时间 t，只剩频率 f；逆变换相反。

Cn（频谱）与 S(f)（频谱密度）的区别（易考点）

项目Cn（周期信号频谱）S(f)（非周期信号频谱密度）
适用对象周期（功率）信号非周期（能量）信号
所用工具傅里叶级数傅里叶变换
谱形态离散谱（线谱）连续谱
单位V（伏特）V/Hz（伏特每赫兹，即频谱“密度”）

共同点：实信号的正、负频率部分都满足复数共轭对称（幅度谱偶对称、相位谱奇对称）。

例题 1：门函数（矩形脉冲，宽度 τ、幅度 1）

求门函数的频谱密度（教材例 2-3 同类）
S(f) = ∫−τ/2τ/2 1·e−j2πft dt = τ·Sa(πfτ) = τ·sin(πfτ) / (πfτ)
（欧拉公式把指数积分化成 sin x / x 形式）主瓣（第一零点）带宽：B ≈ 1/τ（只看正频率半轴）——脉冲越窄（τ 越小），频带越宽。

重要工具：单位冲激函数 δ(t)（理想抽样）

  • 物理意义：宽度无穷小、幅值无穷大、面积为 1 的理想脉冲（∫δ(t)dt = 1，只在 t = 0 处非零）；
  • 性质① 极限表示：δ(t) = limK→∞ (K/π)·Sa(Kt)（抽样函数的极限）；
  • 性质② 筛选（抽样）特性：∫f(t)·δ(t − t0)dt = f(t0)；
  • 性质③ 与阶跃函数的关系：δ(t) = du(t)/dt（单位阶跃的导数）；
  • 频谱：δ(t) ↔ 1（全频段均匀的“白”频谱，常数）；直流 1 ↔ δ(f)。

例题 2：无限长余弦波的频谱密度

s(t) = cos(2πf0t) 的频谱密度
S(f) = ½·[δ(f − f0) + δ(f + f0)]
利用 δ 函数的极限形式推导；把两条 δ 谱线写成抽样函数极限的形式，便于实际实现与抽象分析。
💡 扩充：常用傅里叶变换对（考试直接背）
  • δ(t) ↔ 1；  1 ↔ δ(f)；  e−atu(t) ↔ 1/(a + j2πf)（a > 0）
  • cos(2πf0t) ↔ ½[δ(f−f0) + δ(f+f0)]
  • sin(2πf0t) ↔ (1/2j)·[δ(f−f0) − δ(f+f0)]
  • 门函数 gτ(t) ↔ τ·Sa(πfτ)；  u(t) ↔ 1/(j2πf) + ½δ(f)

2.8能量谱密度 与 功率谱密度

频谱密度 S(f) 回答“频率分量如何分布”，能量谱密度回答“能量如何随频率分布”（类比：概率密度对频率积分得能量）。

2.8.1 能量谱密度 G(f)

G(f) = |S(f)|²   （频谱密度模的平方，也可看作频域上的瞬时功率）

2.8.2 帕塞瓦尔定理（能量守恒 —— 本课核心定理）

E = ∫−∞+∞ s²(t) dt = ∫−∞+∞ |S(f)|² df = ∫−∞+∞ G(f) df
  • 含义：信号时域计算的总能量 = 频域计算的总能量（时域 ↔ 频域能量守恒）；
  • 若 S(f)（或 G(f)）是偶函数：E = 2·∫0∞ G(f) df（单边积分，别忘了 2 倍关系）。
例题：门函数（矩形脉冲）的能量谱密度 上一例题已求 S(f) = τ·Sa(πfτ)，直接取模平方：
G(f) = |S(f)|² = [τ·Sa(πfτ)]² = τ²·Sa²(πfτ)

2.8.3 功率谱密度 P(f)（截短法）

对功率信号先“截短”到 [−T/2, T/2]（取时间窗），得到截短信号 sT(t) 及其傅里叶变换 ST(f)，再取极限：

P(f) = limT→∞ (1/T) · |ST(f)|²

同样满足“能量 / 功率守恒”：功率谱密度对频率积分得到总平均功率。

2.8.4 周期信号的功率谱密度（教材公式 2.2-36，p.24）

总平均功率：P = (1/T0)∫T₀ s²(t) dt = Σn=−∞+∞ |Cn|²（各次谐波功率之和）
功率谱密度：P(f) = Σn=−∞+∞ |Cn|² · δ(f − nf0)
  • |Cn|² 表示第 n 次谐波的功率（C0² 为直流功率）；
  • 周期信号的功率谱是离散的 δ 谱线系列，谱线强度 = 对应谐波功率；
  • 例 2-7：求教材例 2-1 中周期信号的功率谱密度 —— 把级数系数代入上式，结果为 Sa 函数形式。

2.9频率性质（三）· 时域性质：相关函数（了解）

  • 自相关函数（“自”＝针对自身）：衡量同一信号不同时刻取值之间的相关程度，如 s(t) 与 s(t+τ) 的相似性；
  • 互相关函数：衡量两个不同信号之间在某一时刻的相关程度；
  • 本课要求：了解概念；后续章节（随机过程、最佳接收、匹配滤波）会正式使用。
💡 扩充：维纳-辛钦定理（衔接第三章随机过程） 功率信号的功率谱密度 = 自相关函数的傅里叶变换；能量信号的能量谱密度 = 自相关函数的傅里叶变换。 也就是说，频域的谱密度与（时域的）自相关函数是同一信息的两种等价描述——随机信号的谱分析正是靠它铺路。

2.10易错点 · 考试提示 · 第二章思维导图 · 参考资料

⚠️ 易错点清单
  • “频谱”与“频谱密度”：Cn 离散、单位 V；S(f) 连续、单位 V/Hz，别混用；
  • 能量信号与功率信号不是非此即彼：斜坡 x(t)=t·u(t) 两边都不是；
  • 周期信号必属功率信号；而“持续时间无限”只说明“一般”是功率信号，个别情况例外；
  • 求能量别忘了取平方（E=∫s²dt），求周期信号平均功率别忘了 (1/T0) 因子；
  • 能量谱密度是 |S(f)|² 而非 S(f)：取模平方后丢失相位信息；
  • δ(t) 三性质：面积为 1、筛选性 ∫f(t)δ(t−t0)dt = f(t0)、δ(t) = u′(t)；
  • 实信号正负频率共轭对称 ⇒ 幅度谱偶对称、相位谱奇对称；
  • 门函数带宽 B ≈ 1/τ：脉冲越窄（τ 越小）频带越宽（时频对偶）。

第二章思维导图（简版）

  • 确知信号：任意时刻取值已知（数学关系明确）；相对概念——随机信号（噪声 n(t) ⇐ 第三章随机过程）
    • 类型分类
      • ① 周期 / 非周期：T0 基波、f0=1/T0 基频；非周期例：δ(t)、u(t)、指数衰减、高斯脉冲、心电图
      • ② 能量 / 功率：E=∫s²dt（有限→能量）；P=lim(1/T)∫s²dt（有限→功率）；周期信号功率=(1/T0)∫T₀s²dt
    • 频率性质
      • 周期信号 → 傅里叶级数 Cn（离散谱；C0 直流；共轭对称→幅度偶/相位奇）
      • 非周期信号 → 傅里叶变换 S(f)（连续谱密度）；门函数 ↔ τSa(πfτ)、带宽≈1/τ；δ(t)、cos 频谱
    • 谱密度
      • 能量谱密度 G(f)=|S(f)|²；帕塞瓦尔 E=∫s²dt=∫G(f)df（能量守恒）
      • 功率谱密度 P(f)=lim(1/T)|ST(f)|²；周期信号 P(f)=Σ|Cn|²δ(f−nf0)
    • 时域性质：自相关 R(τ) / 互相关；维纳-辛钦定理（谱密度 ⇔ 自相关函数互为正反傅里叶变换）
🚨 课堂花絮：防空警报 = 最简单的时域编码（OOK） 9·18 防空警报其实是通信中的一种时域编码：预警：长响 36s＋短响 24s，持续 3 分钟；空袭：6s 响一次、循环约 15 次，持续 3 分钟；解除：连续长响 3 分钟。 本质是用“响 / 停的时长”携带信息，相当于后续要学的 OOK（On-Off Keying，通断键控）调制——设备最简单、成本最低的调制方式。
